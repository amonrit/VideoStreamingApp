================================================================================
WHAT HAPPENS AUTOMATICALLY
================================================================================

Every time you commit:
  1. Pre-commit hook runs
  2. All Swift files are analyzed
  3. Dependencies are extracted
  4. Snapshot is saved: history/<commit_hash>.json
  5. dependency-map.md is updated
  6. Commit proceeds

✅ This is automatic — no manual steps needed!

================================================================================
REAL-WORLD EXAMPLES
================================================================================

1. Did this commit break something?
   $ python3 .claude/analysis/snapshot-manager.py compare <old_commit>
   → See all new/removed files and dependency changes

2. What's different between two versions?
   $ python3 .claude/analysis/snapshot-manager.py compare v1.0 v2.0
   → See exactly what changed

3. Is the architecture getting messy?
   $ cat .claude/analysis/dependency-map.md
   → Look for circular dependencies or views importing views

4. Revert a commit safely:
   $ git log --oneline | head -3
   $ python3 .claude/analysis/snapshot-manager.py compare <commit_to_revert>
   $ git revert <commit_to_revert>

================================================================================
WARNINGS (Architecture Issues)
================================================================================

❌ CIRCULAR DEPENDENCIES
   Example: View A → View B → View A
   Solution: Use a ViewModel to mediate communication

❌ VIEWS IMPORTING OTHER VIEWS
   Example: ContentView → DetailView → EditView
   Solution: Keep views isolated, use ViewModels

❌ MODELS IMPORTING VIEWS
   Example: PlaybackState → VideoPlayerView
   Solution: Models should never reference Views

❌ TOO MANY IMPORTS IN ONE FILE
   Example: 10+ import statements
   Solution: Split into smaller files

Use comparisons to detect when these are added:
  $ python3 .claude/analysis/snapshot-manager.py compare <commit>
